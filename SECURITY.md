# Security policy

## Supported versions

Fixes are made on the latest `main` branch.

## Reporting a vulnerability

Please do not describe the problem in a public issue, pull request or comment. Contact the
maintainer privately through [mskazemi.com](https://mskazemi.com), and include:

- what an attacker could do,
- the steps to reproduce it,
- the commit you tested.

Never send a real Zenodo token.
